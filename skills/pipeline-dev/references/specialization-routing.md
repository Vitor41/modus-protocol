# Roteamento de especializações

Especialização apoia; o DEV mantém a propriedade da fatia.

| Sinal | Apoio sugerido | Entrega esperada |
|---|---|---|
| Interação complexa, acessibilidade ou responsividade crítica | Frontend | Parecer/implementação delimitada e evidência visual. |
| Contrato de API, concorrência, integração ou autorização transversal | Backend | Contrato, riscos e contribuição delimitada. |
| Migração, integridade, compatibilidade ou rollback de dados | Database | Plano de mudança, validação e reversão. |
| Métrica, granularidade, reconciliação, ETL ou linhagem | BI/Data | Definições, memória de cálculo e reconciliação. |
| Autenticação, segredo, isolamento ou superfície sensível | Security | Ameaças, controles e testes negativos. |

Não acione especialista apenas porque uma camada existe. Registre a justificativa, a fronteira e como a contribuição foi integrada. Não permita escrita paralela conflitante na mesma branch.
